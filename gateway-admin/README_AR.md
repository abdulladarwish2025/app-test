# NetQuota Gateway Admin

تطبيق Android مستقل لإدارة NetQuota Box. هذا التطبيق لا يحتاج VPN ولا يحسب استهلاك الهاتف؛ وظيفته عرض أجهزة الشبكة وإرسال سياسات الحصص والأوامر إلى الـGateway الدائم التشغيل.

## ما يعمل في النسخة الحالية

- واجهة عربية RTL بوضع تجريبي جاهز.
- ملخص الشبكة والحصة الإجمالية.
- مدار حصة مستقل لكل جهاز.
- إيقاف وفتح جهاز.
- إضافة 500 MB أو ضبط حصة 2 GB.
- حفظ عنوان NetQuota Box ومفتاح الإدارة.
- الاتصال بـGateway Core عبر API حقيقية.
- عرض أخطاء الاتصال من دون فقد آخر حالة معروضة.

## استخراج APK من GitHub

1. افتح تبويب **Actions** في مستودع GitHub.
2. اختر **NetQuota Gateway Admin APK**.
3. اضغط **Run workflow**، أو انتظر التشغيل التلقائي بعد رفع الكود.
4. بعد ظهور العلامة الخضراء افتح التشغيل.
5. من قسم **Artifacts** نزّل `NetQuota-Gateway-Admin-APK-...`.
6. فك الملف وثبت `NetQuota-Gateway-Admin.apk` على Android.

ملف SHA-256 مرفق بجانب الـAPK للتحقق من سلامة التنزيل.

## الربط مع المحرك

1. شغل `gateway-core` على كمبيوتر التجربة أو NetQuota Box.
2. اجعل الهاتف والمحرك على نفس الشبكة.
3. من إعدادات التطبيق اكتب عنوانًا مثل `192.168.50.1:8787`.
4. اكتب نفس قيمة `NETQUOTA_ADMIN_TOKEN`.
5. اضغط **حفظ واختبار الاتصال**.

## حدود هذه المرحلة

الـAPK أصبح واجهة إدارة قابلة للبناء والتجربة. فرض الحصص فعليًا يتطلب جهاز Linux/OpenWrt موضوعًا في مسار الإنترنت. محرك `gateway-core` يملك الآن التخزين والحصص والـAPI ووضع المحاكاة؛ تكامل عدادات DHCP وIPv6 الكامل هو المرحلة التالية قبل تشغيله على شبكة حقيقية.
